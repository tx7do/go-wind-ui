暗色中性灰家族接回设计语言规范 §2.3 的近黑蓝系：`--muted` / `--secondary` / `--accent` 四阶 / `--accent-lighter` / `--accent-hover` / `--heavy` / `--border` 只补彩度（hue 240→220、S 0~5%→18~19%），明度一位不动——原值明度本就落在规范的白 α 合成档（α .05~.13 叠 L1 `#111827`），缺的只是蓝调，故版面权重与描边强弱都不变。宿主实测 A/B（同页同视口，1252 元素 / 885,323 加权像素）：零彩度灰带（chroma<0.15）涂装 1196 条 → 0 条，边框 `#36363A`→`#2D3543`、激活页签 `#2E3033`→`#282E39`。

`--ring` 另修一处既有缺陷：原 `222.2 84% 4.9%` = `#020817`，与 L0/L1 同档明度，暗色下焦点环画不出来；改为 `212deg 100% 45% / 25%`。tailwind 的 ring 映射是 `hsl(var(--ring))`、不带 `<alpha-value>` 模板，故 α 烘进三元组（同 `--input` 写法）；包内 `ring-ring` 用法均无 `/α` 修饰符，不会因此失效。

其余 12 个内置配色预设各带一套中性色，不在本口径内。宿主无需改代码，`pnpm update @go-wind/admin-vben` 即生效（vite 不 watch `node_modules`，需重启 dev 服务）。
